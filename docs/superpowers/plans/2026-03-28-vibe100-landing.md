# Vibe100 Landing Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and deploy a single-page email capture landing page for Vibe100 at vibe100.co, wired to Kit form 9259428.

**Architecture:** Single `index.html` file — all HTML, CSS, and JS inline, no build step. Form submissions POST directly to Kit's API endpoint. Deployed via Cloudflare Pages connected to a GitHub repo.

**Tech Stack:** HTML5, CSS3, Vanilla JS, Google Fonts (Syne + IBM Plex Mono), Kit Forms API, Cloudflare Pages

- [ ] **Step 3: Add typewriter JS inside `<script>`**

```javascript
(function () {
  const sentences = [
    "The best way to go from AI-curious to AI-native.",
    "Join and receive a daily prompt every day.",
    "Build with any tool you like.",
    "Share your build and get featured."
  ];

  const el = document.getElementById('tw-text');
  let current = 0;
  let charIndex = 0;
  let isDeleting = false;

  function tick() {
    const text = sentences[current];

    if (!isDeleting) {
      el.textContent = text.slice(0, charIndex + 1);
      charIndex++;
      if (charIndex === text.length) {
        isDeleting = true;
        setTimeout(tick, 1800);
        return;
      }
    } else {
      el.textContent = text.slice(0, charIndex - 1);
      charIndex--;
      if (charIndex === 0) {
        isDeleting = false;
        current = (current + 1) % sentences.length;
        setTimeout(tick, 300);
        return;
      }
    }

    setTimeout(tick, isDeleting ? 25 : 45);
  }

  tick();
}());
```

- [ ] **Step 3: Add form submit JS inside `<script>` (after the typewriter IIFE)**

```javascript
(function () {
  const KIT_ENDPOINT = 'https://app.convertkit.com/forms/9259428/subscriptions';

  const form = document.getElementById('email-form');
  const input = document.getElementById('email-input');
  const btn = document.getElementById('submit-btn');
  const errorEl = document.getElementById('form-error');
  const successEl = document.getElementById('success-msg');

  form.addEventListener('submit', async function (e) {
    e.preventDefault();
    errorEl.textContent = '';

    const email = input.value.trim();
    if (!email || !/^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(email)) {
      errorEl.textContent = 'Please enter a valid email address.';
      input.focus();
      return;
    }

    btn.disabled = true;
    btn.textContent = 'Joining...';

    try {
      const res = await fetch(KIT_ENDPOINT, {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ email_address: email })
      });

      if (!res.ok) throw new Error('Kit API returned ' + res.status);

      form.hidden = true;
      successEl.hidden = false;
    } catch (err) {
      errorEl.textContent = 'Something went wrong. Please try again.';
      btn.disabled = false;
      btn.textContent = 'Join Vibe100';
    }
  });
}());
```
